# Support

ORKS is an early-stage open-source project maintained by one person. There is
no guaranteed support, service-level agreement, response time, consulting
service, or compatibility commitment. Public issues are handled on a
best-effort basis.

For an actionable bug or documentation defect, use the affected repository's
issue tracker and complete the relevant template. Search existing issues first
and provide a minimal, sanitized reproduction.

For a feature proposal, explain the problem and intended outcome rather than
only prescribing an implementation. Acceptance, scheduling, and release are
not guaranteed.

Do not use public support channels for vulnerabilities, credentials, private
research material, personal data, or sensitive logs. Follow the
[Security Policy](SECURITY.md) instead.

Repository-local support documentation overrides this organization default.
