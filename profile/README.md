# Open Research and Knowledge Standard

The Open Research and Knowledge Standard (ORKS) is an open, portable,
local-first effort to make research knowledge durable, inspectable, cited, and
reusable without tying it to one model provider, database, application, or
cloud service.

ORKS is designed around a few core principles:

- people retain ownership of their sources and knowledge;
- derived claims remain traceable to evidence and transformation history;
- generated output is reviewed before it becomes canonical knowledge;
- portable files are canonical while indexes and caches are rebuildable;
- useful CPU-only operation is a baseline, not a fallback afterthought;
- security, privacy, resource use, and network exposure fail closed.

The project is in early development. Public repositories will appear in this
organization as their scope and verification gates are ready.

See the organization-wide [contribution guidance](../CONTRIBUTING.md),
[security policy](../SECURITY.md), and [code of conduct](../CODE_OF_CONDUCT.md)
before participating.
