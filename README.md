# Open Research and Knowledge Standard organization defaults

This repository contains the public community-health defaults for repositories
in the Open Research and Knowledge Standard GitHub organization.

It owns the organization profile, contribution and DCO guidance, code of
conduct, security and support policies, and issue and pull-request templates.
An individual repository may override these defaults when its own contract
needs more specific guidance.

ORKS is in early development. Public specifications and implementation
repositories will be published only when their scope and verification gates
are ready.
